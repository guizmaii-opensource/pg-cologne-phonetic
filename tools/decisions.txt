# tools/generate_corpus.sh fails if a disagreement has no line here.

# Every disagreement so far comes from one place: what the "last emitted code" is after a vowel
# or an H. Kölner Phonetik (Postel 1969; see the German Wikipedia article) is three steps:
#   1. code every letter with the table;
#   2. collapse runs of identical adjacent codes to one digit;
#   3. drop every 0 except a leading one.
# Step 2 runs before step 3, so two identical codes separated by a 0 stay two digits
# (Hoffmann -> 0366), while two identical codes separated only by an H, which has no code at
# all, are adjacent and collapse (Mülhler -> 657).
#
# Apache Commons Codec >= 1.22.0 (CODEC-317) collapses in both situations (Hoffmann -> 036),
# rphonetic 3.1.0 (a port of Commons <= 1.21) collapses in neither (Mülhler -> 6557).
# Each line below picks the reference that follows the three steps for that input. Choosing
# 0366 for Hoffmann also keeps codes compatible with 15 years of Commons Codec releases and
# with the examples published for the algorithm.
